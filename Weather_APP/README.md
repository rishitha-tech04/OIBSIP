# Weather App

## Description
A simple Python program that displays weather information for a city using a weather API.

## Features
- Takes city name as input
- Displays temperature
- Displays humidity
- Displays weather condition
- Displays wind speed
- Handles invalid city names and API errors

## Technologies Used
- Python
- Requests
- OpenWeatherMap API
